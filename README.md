# Nepali Call Break Scorekeeper

Interactive 5-round scorekeeper for a 4-player Nepali Call Break card game.

## Local development

```bash
npm install
npm run dev
```

## Build & deploy

```bash
npm run build
npm run deploy
```

`npm run deploy` publishes the `dist/` folder to Shipstatic and prints the live URL.
